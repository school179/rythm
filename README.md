# Ритм — трекер привычек и целей

Устанавливаемое веб-приложение (PWA): привычки, цели, календарь, статистика, настроение и достижения.
Работает без интернета, все данные хранятся на устройстве.

## Публикация на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `ritm`.
2. Нажмите **Add file → Upload files** и перетащите все файлы и папку `icons` из этого архива. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ_ЛОГИН.github.io/ritm/`.

## Установка на телефон

- **Android (Chrome):** откройте ссылку → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран „Домой“».

## Обновление

Замените `index.html` в репозитории новой версией. Чтобы установленное приложение точно подхватило изменения, поменяйте строку `VERSION` в `sw.js` (например, на `ritm-v2`).

## Резервная копия

Настройки → «Скачать копию» сохраняет файл `.json`. Через «Загрузить из файла» данные переносятся на другое устройство.
